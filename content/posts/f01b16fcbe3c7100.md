（本网讯）2012年10月14日，瑞士中国学人科技协会在瑞士首都伯尔尼Reberhaus Bolligen文化中心召开2012年年会暨首届旅瑞学生学者中秋音乐会，来自全瑞各地的旅瑞学生、学者及驻瑞中资机构专家代表一百余人出席了这一活动，中国驻瑞士大使馆吴恳大使、孙玲参赞应邀莅临年会现场。<br/>
 <br/>
<a href="/media/f276ffa3251cab153e4503a5.jpg"><img alt="W0201210193863042063621" class="attachment-full" decoding="async" height="332" loading="lazy" src="/media/f276ffa3251cab153e4503a5.jpg" title="W0201210193863042063621" width="500"/></a><br/>
 <br/>
中国驻瑞士大使馆吴恳大使发表了热情洋溢的讲话，大使首先对科协年会的召开表示热烈祝贺，并对科协的工作给予了高度的肯定。他说，很高兴在到任之后连续第三年出席科协年会。科协自成立以来，积极通过多种渠道为旅瑞学生学者搭建交流平台，为拓展中瑞科教领域交流合作发挥了积极作用。之后，吴恳大使通过生动的事例和翔实的数据回顾和缕析了新中国成立后中瑞关系的发展历程和重要事件，详细介绍了现今中瑞双边政治、经济、文化、科教等领域合作交流所取得的一系列丰硕成果，深刻分析并展望了中瑞关系的发展潜力和前景，并对瑞士中国学人科技协会和广大旅瑞学生学者提出了殷切的希望。他说，希望大家做好祖国的“名片”和中瑞友谊的“桥梁”，为进一步深化中瑞两国民间交往，扩大两国在科教等领域的互利务实合作做出更大贡献。吴大使的讲话使在场人员深受鼓舞。大家纷纷表示，吴大使的介绍加深了大家对中瑞关系的认识，要努力以不同方式积极促进两国人民之间的沟通和相互了解，为祖国的繁荣富强和中瑞关系发展贡献自己的力量。<br/>
 <br/>
<a href="/media/9e69866e79ee705b40efa118.jpg"><img alt="W0201210193863042182531" class="attachment-full" decoding="async" height="318" loading="lazy" src="/media/9e69866e79ee705b40efa118.jpg" title="W0201210193863042182531" width="500"/></a><br/>
随后，华为瑞士公司财务总监李福平先生和与会学生学者分享了华为公司海外开拓的历程，并与大家一起交流了中国企业海外发展的心得体会；中国驻瑞士大使馆教育处孙玲参赞就最近瑞士联邦政府教育科研管理体制改革为大家进行了深入浅出的分析，并就瑞士高等教育、职业教育的诸多特色以及瑞士科研创新的独特体系及其优势进行了全方位的剖析。这一系列贴近旅瑞学生学者工作生活实践的精彩的报告博得了与会听众阵阵热烈的掌声。最后，科协主席丰建华先生代表科协理事会向大家报告了科协在过去一年开展的一系列卓有成效的工作并对科协未来的工作进行了展望。<br/>
 <br/>
<a href="/media/f53f6e12ab07ed22f409725f.jpg"><img alt="W0201210193863042157021" class="attachment-full" decoding="async" height="250" loading="lazy" src="/media/f53f6e12ab07ed22f409725f.jpg" title="W0201210193863042157021" width="500"/></a><br/>
年会之后，首届旅瑞学生学者中秋音乐会拉开了帷幕，来自全瑞各地的外国友人数十人也来到了音乐会现场，和大家一同聆听来自苏黎世、巴塞尔、卢加诺等地的旅瑞青年艺术家们以女声独唱、钢琴独奏、长笛独奏等方式诠释的一系列中外经典音乐作品，旅瑞青年歌唱家邵露女士一曲“我爱你中国”更是将全场音乐会推向了高潮。整台音乐会中西合璧，精彩纷呈，赢得观众经久不息的热烈掌声。<br/>
 <br/>
瑞士中国学人科技协会成立于2004年7月，是以旅瑞中国学生学者为主体的非盈利民间专业组织。历经近10年的发展，目前协会共拥有注册会员近600人，其中绝大多数拥有博士学位或在读博士，会员广泛分布在瑞士境内的各大城市的高端企业、研究院所、高校和金融行业。（供稿/驻瑞士使馆教育处）<br/>
