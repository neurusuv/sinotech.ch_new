<p><span style="font-size:14pt">      浙江，位于我国东南沿海，地处长江三角洲南翼，下辖11个省辖市。改革开放以来，浙江人民发扬与时俱进的浙江精神，创出了一条具有浙江特色的发展路子，走在了全国经济社会发展前列。杭州是浙江省省会，全省经济、科教、文化中心，著名的国际风景旅游城市。杭州经济发达、自然环境优美，是包括海外留学人才在内的各类优秀人才宜业宜居之城。</span></p>
<div style="text-indent:24.8pt;line-height:16pt"><span style="font-size:14pt">为大力推进全省经济转型升级，积极应对国际金融危机，更好地服务“创业富民、创新强省”的总战略。经研究，决定于今年11月份举办“2009浙江·杭州国际人才交流与合作大会”，进一步加强与海外高层次人才的交流与合作，吸引更多海外高层次留学人才来浙（杭）创业。现将有关事项公告如下：</span></div>
<div align="left" style="margin:0 0 0 32.3pt;line-height:16pt;text-align:left"><strong><span style="font-size:14pt">一、活动承办单位</span></strong></div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left"><span style="font-size:14pt">浙江省人才工作办公室</span></div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left"><span style="font-size:14pt">浙江省人力资源和社会保障厅</span></div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left"><span style="font-size:14pt">杭州市人才工作办公室</span></div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left"><span style="font-size:14pt">杭州市人事局</span></div>
<div align="left" style="margin:0 0 0 32.3pt;line-height:16pt;text-align:left"><strong><span style="font-size:14pt">二、活动时间、地点和内容</span></strong></div>
<div align="left" style="margin:0 0 0 32.3pt;line-height:16pt;text-align:left">
<strong><span style="font-size:14pt">（一）百名海外高层次人才浙江行·海外创业人才与项目洽谈会</span></strong><span style="font-size:14pt"> <span>  </span></span>
</div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left"><span style="font-size:14pt">时间：11月5日-6日<span>   </span>地点：杭州市</span></div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left">
<span style="font-size:14pt">1</span><span style="font-size:14pt">、海外留学人才创业项目对接洽谈；</span>
</div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left">
<span style="font-size:14pt">2</span><span style="font-size:14pt">、海外留学人才技术项目合作推介、洽谈；</span>
</div>
<div align="left" style="margin:0 0 0 53.25pt;text-indent:-21pt;line-height:16pt;text-align:left">
<span style="font-size:14pt">3</span><span style="font-size:14pt">、海外留学人才与国内单位合作项目洽谈；</span>
</div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left">
<span style="font-size:14pt">4</span><span style="font-size:14pt">、海外留学人才社团合作交流；</span>
</div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left">
<span style="font-size:14pt">5</span><span style="font-size:14pt">、海外高层次留学人才交流；</span>
</div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left">
<span style="font-size:14pt">6</span><span style="font-size:14pt">、赴杭州市相关园区考察投资和创业环境。</span>
</div>
<div align="left" style="margin:0 0 0 32.25pt;line-height:16pt;text-align:left"><strong><span style="font-size:14pt">（二）后续活动</span></strong></div>
<div align="left" style="text-indent:28pt;line-height:16pt;text-align:left">
<span style="font-size:14pt">11</span><span style="font-size:14pt">月7日</span><span style="font-size:14pt">始，根据项目对接情况，由浙江省内相关市、单位自行组织赴各地、各单位进行深入洽谈和实地考察。</span>
</div>
<div align="left" style="margin:0 0 0 32.3pt;line-height:16pt;text-align:left"><strong><span style="font-size:14pt">三、邀请参会对象</span></strong></div>
<div align="left" style="text-indent:27.55pt;line-height:16pt;text-align:left">
<strong><span style="font-size:14pt">（一）海外留学人才：</span></strong><span style="font-size:14pt">一是取得硕士学位，在国外大学、企业或研究机构担任专业工作三年以上的留学人员；二是取得博士学位的留学人员；三是在产业、专业领域具有独特影响力的海外华人专才；四是在产业、专业领域具有独特影响力的海外留学人才创新创业团队。已在国内工作、创业的海外高层次留学人才也可报名参会。</span>
</div>
<div align="left" style="text-indent:27.55pt;line-height:16pt;text-align:left">
<strong><span style="font-size:14pt">（二）国内单位：</span></strong><span style="font-size:14pt">浙江各市政府人事部门、留学人员创业园以及高校、科研院所等企事业单位；杭州市有关政府部门、开发区、留学人员创业园、科技园、投融资机构、企事业单位；省外受邀城市代表团。</span>
</div>
<div align="left" style="margin:0 0 0 32.3pt;line-height:16pt;text-align:left"><strong><span style="font-size:14pt">四、人才项目征集</span></strong></div>
<div align="left" style="text-indent:28pt;line-height:16pt;text-align:left"><span style="font-size:14pt">大会面向海内外征集海外留学人才与项目信息，欢迎海内外留学人才提供来浙（杭）工作意向、来浙（杭）创业意向，以及与浙江杭州企事业单位进行项目合作的信息，大会将提供人才项目对接平台。</span></div>

</div>
